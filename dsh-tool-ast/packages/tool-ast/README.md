# @hy-sde-org/dsh-tool-ast

The `ast_grep` (structural code search) and `ast_edit` (structural rewrite)
tools for DeepSeek Harness over the packaged ast-grep native engine.

```bash
dsh plugin --profile web add @hy-sde-org/dsh-tool-ast
```

Full usage, configuration, and the relationship to the harness's own edit
tooling: https://github.com/hy-sde/dsh-tool-ast#readme
